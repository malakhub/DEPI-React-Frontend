CSS Layout & Positioning Assignment

Goal: Build a webpage layout using CSS positioning, selectors, and box model properties you've learned.

This assignment pulls together everything covered in class. You'll be creating a styled layout from scratch. Check the tasks.txt file for step-by-step instructions.

Getting Started

You'll need to create an HTML file and a CSS file. Here's a basic structure to get you started:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Layout</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <!-- Add your content here -->
</body>
</html>

Open tasks.txt for your assignment details.
